# برومبت - تنظيم صفحة المنتجات والنافبار - PikaVive

انسخ الكلام ده وابعته لـ Replit كامل:

---

عايز أظبط الموقع بالشكل ده بالظبط:

## 1. الصفحة الرئيسية (Home) - تبقى بسيطة جدًا
تحتوي بس على:
- Hero Section (بانر رئيسي جذاب بصورة قوية + عنوان + زرار CTA)
- قسم "الأكثر مبيعًا / أشهر المنتجات" (عدد محدود، مثلاً 6-8 منتجات)
- قسم "الخصومات والعروض" (المنتجات اللي عليها خصم)
- زرار واضح "تسوق كل المنتجات" يوجّه لصفحة المنتجات الكاملة
- ملاحظة: مفيش زحمة، الصفحة الرئيسية للعرض السريع بس مش لعرض كل حاجة

## 2. صفحة المنتجات (Products Page) - صفحة منفصلة قائمة بذاتها
- تعرض **كل المنتجات** بتاعة المتجر في صفحة واحدة منظمة (Grid Layout شيك واحترافي)
- **فلتر قوي وفعّال** يشمل:
  - فلترة حسب القسم (مطبخ - تنظيف - تخزين - إلخ)
  - فلترة حسب السعر (من - إلى)
  - ترتيب حسب (الأحدث - الأقل سعرًا - الأعلى سعرًا - الأكثر مبيعًا)
  - الفلتر يكون Sidebar واضح على الشاشات الكبيرة، وDropdown/Bottom Sheet على الموبايل
- كل منتج في كارت أنيق (صورة - اسم - سعر - زرار سريع "أضف للسلة")
- الصور المستخدمة تكون **صور حقيقية واحترافية** (من Unsplash) تناسب كل منتج فعليًا، مش صور عشوائية أو placeholder
- شكل الصفحة "شيك" يعني: مسافات مريحة بين الكروت، ظل خفيف عند hover، انتقال سلس (transition) عند تحميل المنتجات

## 3. النافبار (Navbar) - احترافي مع Dropdown
- روابط قليلة ومركّزة بس (الحاجات المهمة فقط): الرئيسية - المنتجات - من نحن - تواصل معنا
- رابط "المنتجات" يكون بيه **Dropdown List احترافي** يظهر عند الـ hover/click، فيه الأقسام الفرعية (مطبخ، تنظيف، تخزين...) كل قسم يوديك مباشرة لصفحة المنتجات مفلترة على القسم ده
- الـ Dropdown يظهر بانيميشن ناعم (fade/slide) مش يظهر فجأة
- استخدم transition خفيف على كل الروابط والأزرار عند الـ hover (تغيير لون تدريجي، مش فجائي)
- خلي الـ Navbar ثابت (Sticky) أعلى الصفحة عند السكرول

## 4. مبدأ عام مهم
- التركيز على الأساسيات فقط، من غير روابط أو عناصر زيادة تشتت الانتباه
- كل شيء يعكس هوية براند PikaVive (الألوان اللي اتفقنا عليها: `#C8722E` / `#3D2A1E` / `#E8DFD0`) والخط Cairo/Tajawal
