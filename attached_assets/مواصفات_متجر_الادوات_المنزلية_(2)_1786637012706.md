# مواصفات مشروع: متجر إلكتروني لبيع الأدوات المنزلية

## اسم المتجر: PikaVive

## 1. فكرة المشروع
متجر إلكتروني (React) باسم **PikaVive** لعرض وبيع الأدوات المنزلية (مطبخ، تنظيف، تخزين، أدوات كهربائية منزلية، إلخ)، مع نظام سلة شراء، وإتمام الطلب عن طريق التواصل المباشر على واتساب بدلاً من الدفع الإلكتروني.

**رقم واتساب التواصل:** 01023279424 (يُستخدم بصيغة دولية في الكود: 201023279424)

**اللوجو:** هيتم رفعه يدويًا من صاحب المتجر ووضعه في الـ Navbar (الهيدر) بجانب/بدل اسم المتجر النصي. يُفضّل أن يكون الكود جاهز لاستقبال ملف صورة اللوجو (مثلاً `src/assets/logo.png`) مع مساحة مخصصة له في مكون الـ Header بحجم مناسب (مثلاً height: 40-50px) ورابط يوجّه للصفحة الرئيسية عند الضغط عليه.

---

## 2. الستاك التقني المطلوب
- **Frontend:** React (باستخدام Vite)
- **Styling:** Tailwind CSS
- **State Management:** React Context API أو Zustand (للسلة والمفضلة)
- **Routing:** React Router
- **تخزين البيانات:** 
  - في البداية: بيانات المنتجات في ملف JSON/JS محلي (لسهولة البدء بدون باك اند)
  - اختياري لاحقًا: Firebase Firestore لتخزين المنتجات والطلبات فعليًا
- **الصور:** استضافة على الإنترنت (روابط) أو مجلد assets محلي
- **التصميم:** متجاوب بالكامل (Responsive) - موبايل أولاً (Mobile First) لأن أغلب الزوار من الموبايل

---

## 3. الصفحات الأساسية

### أ) الصفحة الرئيسية (Home)
- Banner/Slider ترويجي لأهم العروض
- أقسام المنتجات (كروت أقسام: مطبخ - تنظيف - تخزين - حمام - كهربائيات منزلية...)
- قسم "الأكثر مبيعًا" أو "وصل حديثًا"
- قسم مميزات المتجر (توصيل سريع - جودة مضمونة - تواصل مباشر واتساب)
- Footer فيه بيانات التواصل والروابط

### ب) صفحة كل قسم (Category Page)
- عرض المنتجات كـ Grid (كروت منتجات)
- فلاتر: حسب السعر - حسب التقييم - الأحدث
- خانة بحث
- Pagination أو Load More

### ج) صفحة تفاصيل المنتج (Product Details)
- صور المنتج (Gallery / Zoom)
- اسم المنتج - السعر - السعر قبل الخصم (لو فيه عرض)
- وصف كامل للمنتج + المواصفات (مقاس - لون - خامة - إلخ)
- اختيار الكمية
- زرار "أضف للسلة"
- زرار "اطلب الآن عبر واتساب" (يفتح واتساب مباشرة برسالة جاهزة فيها اسم المنتج والسعر)
- منتجات مشابهة / قد يعجبك أيضًا

### د) صفحة السلة (Cart)
- عرض المنتجات المضافة (صورة - اسم - سعر - كمية - إجمالي)
- إمكانية تعديل الكمية أو الحذف
- عرض الإجمالي الكلي
- زرار "إتمام الطلب عبر واتساب"

### هـ) صفحة إتمام الطلب (Checkout بسيط)
- فورم بيانات العميل: الاسم - رقم الهاتف - العنوان بالتفصيل - ملاحظات
- عند الضغط على "إرسال الطلب": يتم تجميع بيانات الفورم + محتويات السلة في رسالة منسقة، ويفتح رابط واتساب تلقائيًا بهذه الرسالة جاهزة للإرسال

### و) صفحة "من نحن" (About)
- نبذة عن المتجر ورؤيته

### ز) صفحة "تواصل معنا" (Contact)
- رقم الواتساب مع زرار تواصل مباشر
- (اختياري) رقم تليفون - إيميل - عنوان - خرائط جوجل
- روابط السوشيال ميديا (فيسبوك - انستجرام - تيك توك)

### ح) صفحة المفضلة (Wishlist) - اختياري
- حفظ المنتجات المفضلة للمستخدم (localStorage)

## 4. المميزات الرئيسية المطلوبة

### 🛒 نظام السلة
- إضافة/حذف/تعديل كمية المنتجات
- حفظ السلة في localStorage (تفضل لو المستخدم قفل الصفحة ورجع)
- عداد المنتجات يظهر على أيقونة السلة في الهيدر

### 💬 التكامل مع واتساب (أهم ميزة)
- زرار "واتساب" عائم (Floating Button) ثابت في كل الصفحات للتواصل السريع
- عند الطلب: يتم بناء رابط بالشكل:
  ```
  https://wa.me/201023279424?text=رسالة_الطلب_المُنسقة
  ```
- الرسالة تتضمن تلقائيًا: اسم العميل، المنتجات المطلوبة، الكميات، الأسعار، الإجمالي، العنوان

### 🔍 البحث
- خانة بحث في الهيدر تدور في كل المنتجات بالاسم

### 🗂️ الفلترة والتصنيف
- تصنيف حسب القسم
- ترتيب حسب (الأقل سعرًا - الأعلى سعرًا - الأحدث - الأكثر شهرة)

### 📱 تصميم متجاوب بالكامل
- يعمل بشكل مثالي على الموبايل والتابلت والديسكتوب

### ⭐ تقييمات المنتجات (اختياري)
- عرض تقييم بالنجوم لكل منتج

### 🏷️ نظام العروض والخصومات
- إمكانية عرض "خصم %" على منتجات معينة مع عرض السعر القديم مشطوب

### 🌙 دعم اللغة العربية بالكامل (RTL)
- الموقع بالكامل من اليمين لليسار
- خط عربي واضح ومناسب (مثل Cairo أو Tajawal من Google Fonts)

### ⚡ لوحة تحكم بسيطة (اختياري - مرحلة لاحقة)
- صفحة أدمن لإضافة/تعديل/حذف المنتجات (تحتاج باك اند مثل Firebase)

- أيقونة بحث
- أيقونة سلة (مع عداد المنتجات)
- أيقونة مفضلة (اختياري)
- Menu همبرجر للموبايل

- روابط سريعة
- بيانات التواصل (واتساب - إيميل)

## 9. مثال لدالة إرسال الطلب لواتساب
```javascript
function sendOrderToWhatsApp(customerInfo, cartItems, total) {
  const phone = "201023279424";
  let message = `مرحباً PikaVive، أريد تأكيد طلب جديد 🛒%0A%0A`;
  message += `الاسم: ${customerInfo.name}%0A`;
  message += `العنوان: ${customerInfo.address}%0A`;
  message += `رقم الهاتف: ${customerInfo.phone}%0A%0A`;
  message += `تفاصيل الطلب:%0A`;
  cartItems.forEach(item => {
    message += `- ${item.name} × ${item.quantity} = ${item.price * item.quantity} جنيه%0A`;
  });
  message += `%0Aالإجمالي: ${total} جنيه`;
  
  window.open(`https://wa.me/${phone}?text=${message}`, "_blank");
}
```

## 10. الألوان والهوية البصرية (Brand Colors - PikaVive)
- **Burnt Orange `#C8722E`** — للعناوين الرئيسية وأزرار الـ CTA الأساسية (أضف للسلة، اطلب الآن، إرسال الطلب...)
- **Dark Brown `#3D2A1E`** — للنص الأساسي والعناوين الفرعية
- **Cream/Beige `#E8DFD0`** — الخلفية الأساسية للبراند (خلفية الصفحة العامة)
- خط: Cairo أو Tajawal (خط عربي حديث)

### إعداد الألوان في Tailwind (tailwind.config.js)
```javascript
theme: {
  extend: {
    colors: {
      'pika-orange': '#C8722E',
      'pika-brown': '#3D2A1E',
      'pika-cream': '#E8DFD0',
    }
  }
}
```
ثم تُستخدم في الكود بالشكل: `bg-pika-orange` / `text-pika-brown` / `bg-pika-cream`

## 11. نقاط إضافية مهمة
- **زرار واتساب عائم**: أسفل يمين الشاشة، ثابت في كل الصفحات، بأيقونة واتساب الخضراء
- **رسائل تأكيد**: عند إضافة منتج للسلة تظهر رسالة صغيرة (Toast) "تمت الإضافة بنجاح"
- **صفحة 404** مخصصة لو المستخدم دخل رابط غير موجود
- **سرعة التحميل**: ضغط الصور واستخدام Lazy Loading
- **SEO بسيط**: عناوين وصفية لكل صفحة
