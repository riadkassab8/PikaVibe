### 1. Cursor / Clickable Actions

* Add `cursor: pointer` to **every clickable/actionable element** across the website.
* This includes:

  * Buttons
  * Product cards
  * Add to Cart
  * Cart icon
  * Wishlist buttons
  * Quantity controls
  * Navigation links
  * Language switcher
  * Checkout actions
  * Close/back buttons
  * Any icon that performs an action
* Make sure disabled elements still look disabled and should **not** show a pointer cursor.

### 2. Add to Cart Animation

Create a polished animation when the customer clicks **Add to Cart**.

Requirements:

* Give immediate visual feedback after clicking.
* Button should smoothly animate from its normal state to a success state.
* Example flow:

  * `Add to Cart` → subtle press animation → `✓ Added to Cart`
  * Then return to the normal state.
* Animate the cart icon/badge when the product is added.
* If possible, add a subtle product-to-cart animation without hurting performance.
* Prevent duplicate clicks while the add-to-cart action is processing.
* Animation must work perfectly on both desktop and mobile.
* Keep it elegant and fast, not exaggerated.

### 3. Arabic Language Support

Add **Arabic (العربية)** as a complete language option.

Requirements:

* Add a language switcher for **English / العربية**.
* Translate all user-facing UI text, including:

  * Navigation
  * Buttons
  * Product information
  * Cart
  * Checkout
  * Forms
  * Validation messages
  * Empty states
  * Success/error messages
  * Order confirmation
  * Footer
  * Any remaining hardcoded UI text
* Arabic must use proper **RTL layout**.
* When Arabic is selected:

  * Set the document direction to `rtl`.
  * Correctly mirror layouts where appropriate.
  * Align text, icons, spacing, forms, navigation, and checkout components correctly.
* English remains `LTR`.
* Persist the selected language so refreshing the page does not reset it.
* Do not simply translate a few labels; make the entire customer journey usable in Arabic.
